14. Admin Dashboard
Admin web dashboard should prioritize speed. The most important workflow is: enter Customer ID → enter purchase
amount → see calculated points → add purchase.
Dashboard metrics: total customers, active/inactive customers, points issued, redeemable points, redeemed points,
today's transactions and purchase value.
Customer table: ID, name, phone, points, status, last transaction and actions.
Customer details: ID, name, phone, status, current/redeemable/pending points, last transaction and activity deadline;
tabs for overview, purchases, points and redemptions.
Admin must never manually enter final points; backend calculates them.
Use protected admin routes and never expose service-role keys.
